# 카드뉴스 제작 시스템

* template.html: 카드 뉴스 공통 디자인 시스템(색상 변수, 폰트, 카드 레이아웃, 태그/포인트/스탯 컴포넌트) 단독 파일
* build.py: 이 템플릿에 각 카드별 내용(타이틀, 본문, 태그 색상 등)을 채워 넣어 cardN_*.html을 생성하는 스크립트
* shoot.py: Playwright로 각 html을 1080×1350 PNG로 캡처하는 스크립트
cardnews_templates.zip: 위 세 파일 + 카드별 완성 html 7개 + 마스코트/로고 이미지(images/)까지 전부 포함한 압축본

깃헙 레포에 통째로 넣고, 다음 달 모임 때는 build.py 안의 카드별 텍스트 블록만 새 내용으로 바꾼 뒤 shoot.py 실행하면 같은 톤으로 카드뉴스를 다시 뽑을 수 있어요.

# 회의록 → 인사이트 카드뉴스 변환 프롬프트

AI 빌더모임처럼 여러 대표·빌더가 각자 회사/고객사 이야기를 섞어서 나누는 회의록을,
**기업 NDA·고객사 식별 정보 없이** 일반적으로 통하는 "인사이트"로 재구성할 때 쓰는 프롬프트입니다.
녹취록을 붙여넣고 아래 지시문을 그대로 사용하세요.

---

## 프롬프트

```
다음은 AI 빌더모임 회의록(녹취 전문)이다. 이 내용을 카드뉴스용 "인사이트"로
재구성해줘. 아래 규칙을 반드시 지켜라.

[제외할 것 — NDA/식별 정보]
- 특정 회사명, 대표 실명, 고객사명, 브랜드명(예: 실제 화장품 브랜드, 실제 프랜차이즈명 등)
- 매출액, 계약 단가, 인건비 등 특정 기업을 특정할 수 있는 구체적 숫자
- "누가 어디서 무엇을 했다"는 식의 1:1 사례 서술
- 지역명, 특정 미팅 정황(예: 어느 회사 이사님과 몇 시간 미팅) 등 맥락상 신원이 드러나는 디테일

[추출할 것 — 인사이트]
- 여러 발언에서 공통으로 관통하는 "원칙" 또는 "패턴" (예: "AI는 반복 작업을 대체하지만
  판단과 손맛이 필요한 영역은 여전히 사람이 채운다")
- 특정 사례가 아니라 일반화된 통찰: "~하는 경우가 많다", "~라는 공통된 경험이 있었다"
- 숫자를 쓰더라도 특정 기업이 아닌 업계 전반의 감각으로 표현 (예: "인건비 비중이
  절반을 넘는 기업도 드물지 않다" 처럼 범위/경향으로)
- 실행 가능한 시사점(그래서 무엇을 해야 하는가) 또는 사고를 자극하는 질문 형태

[톤 & 형식]
- 카드 1장당 하나의 인사이트만 담을 것 (여러 주제를 욱여넣지 말 것)
- 타이틀은 한 문장, 임팩트 있게 (13자 내외 권장, 길어도 20자 이내)
- 서브타이틀 1문장으로 맥락 보충
- 근거/설명은 불릿 2~3개, 각 1문장
- 말투는 단정적이되 거만하지 않게, "~다" 체 유지
- 특정 기업이 떠오르는 표현 대신 "한 참가자는", "현장에서는", "빌더들 사이에서는" 같은
  익명화된 주어 사용

[출력 형식]
회의록 전체에서 인사이트를 최소 5개, 최대 8개 뽑아서 아래 형식으로 정리:

## 인사이트 N
- 한 줄 제목:
- 한 줄 부연:
- 근거 불릿 2~3개:
- (선택) 이 인사이트가 나온 배경 카테고리: 예) 게임 개발 / 비즈니스 모델 / 조직·생산성 / 커뮤니티

[회의록]
(여기에 녹취 전문 붙여넣기)
```

---

### 사용 팁
- 프롬프트 안의 [회의록] 자리에 원문 전체를 붙여넣고 실행하면, 카드뉴스 제작 전 단계인
  "인사이트 목록"이 먼저 나옵니다. 이 목록을 검토·수정한 뒤 카드 텍스트로 넘어가는 게
  한 번에 카드뉴스로 바로 뽑는 것보다 훨씬 안전합니다 (NDA 리스크 최소화 + 내용 검수 가능).
- 인사이트 목록을 확인하신 후 "이 중 이런 인사이트로 카드뉴스 만들어줘" 라고 알려주시면
  그 인사이트들로 카드뉴스 카피를 다시 작성하겠습니다.
