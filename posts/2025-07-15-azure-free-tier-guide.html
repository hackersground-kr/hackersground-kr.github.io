☁️ Azure 무료 크레딧으로 할 수 있는 것들 총정리

학생 계정, 스타트업 크레딧, 무료 티어 서비스까지 — 돈 안 쓰고 클라우드 실습하는 법 · 2025-07-15 · 해커그라운드

어떤 무료 크레딧이 있나요?

Azure에는 생각보다 많은 무료 방법이 있어요. 상황에 맞는 걸 골라쓰면 돼요.

1. Azure 무료 계정 (개인)

  • 가입 후 12개월 동안 인기 서비스 무료
  • $200 크레딧 (30일 사용 가능)
  • 55가지 서비스는 영구 무료
  • 가입: azure.microsoft.com/ko-kr/free

2. Azure for Students

  • 대학 이메일 (.ac.kr, .edu)로 가입
  • $100 크레딧 / 연 갱신 가능
  • 신용카드 없이 가입 가능 🎉
  • GitHub Student Developer Pack과 연동

3. Microsoft for Startups (Founders Hub)

  • 스타트업이라면 최대 $150,000 크레딧
  • GitHub Copilot Enterprise 포함
  • 팀이 있다면 꼭 신청해보세요

영구 무료 서비스 (Always Free) 꿀팁

  • Azure Static Web Apps — 정적 사이트 무제한 배포
  • Azure Functions — 월 100만 건 요청 무료
  • Azure Cosmos DB — 1,000 RU/s + 25GB 무료
  • Azure SQL Database — 100,000 vCore 초/월 무료
  • Azure Container Registry — 기본 티어 1개 무료

실습 아이디어

  • 포트폴리오 사이트 → Azure Static Web Apps
  • AI 챗봇 → Azure OpenAI + Azure Functions
  • 간단한 API → Azure Functions + Cosmos DB
  • CI/CD 파이프라인 → GitHub Actions + Azure App Service
학생이라면 Azure for Students 먼저! 신용카드 없이 시작할 수 있어요. 12개월마다 갱신되니 졸업 전까지 알차게 써보세요.
