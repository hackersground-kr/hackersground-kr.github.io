## 기본 단축키 (VS Code 기준)

- `Tab` — 제안 수락
- `Esc` — 제안 거절
- `Alt + ]` / `Alt + [` — 다음/이전 제안 보기
- `Ctrl + Enter` — 패널에서 여러 제안 한꺼번에 보기
- `Ctrl + I` — Copilot 인라인 채팅 열기

## 주석으로 코드 유도하기

Copilot은 주석을 기반으로 코드를 생성해요. 주석을 자세하게 쓸수록 더 정확한 코드가 나와요.

- "함수 만들어줘" ❌
- "주어진 배열에서 중복을 제거하고 내림차순으로 정렬하는 함수" ✅

## Copilot Chat 활용 패턴

- `/explain` — 선택한 코드 설명해줘
- `/fix` — 에러 고쳐줘
- `/tests` — 유닛 테스트 생성
- `/doc` — 문서 주석 생성
- `@workspace` — 전체 프로젝트 컨텍스트로 질문

## 꿀팁 모음

- 파일 맨 위에 목적을 주석으로 써두면 전체적으로 더 맥락에 맞는 제안이 와요
- 테스트 코드 먼저 작성하면 Copilot이 구현을 맞춰서 생성해요 (TDD 친화적)
- 여러 줄 삭제 후 다시 타이핑하면 더 나은 버전 제안을 받을 수 있어요
- 영어 주석이 한국어보다 제안 품질이 조금 더 높은 경향이 있어요

> Copilot은 페어 프로그래밍 파트너예요. 제안을 무조건 믿지 말고, 리뷰하는 습관을 들이세요.
